# \## Part 1: Setting up your development environment

# 

# \### 1. Install the required tools

# 

# Before starting the practical session, make sure the following tools are installed on your computer.

# 

# \#### Python

# 

# Ensure that Python is installed on your system.

# 

# \#### Git and GitHub

# 

# Install Git on your computer and create a GitHub account if you do not already have one.

# 

# \#### Miniconda

# 

# Install Miniconda on your system using the official documentation:

# 

# \[Miniconda Installation Guide](https://www.anaconda.com/docs/getting-started/concepts/anaconda-or-miniconda)

# 

# \---

# 

# \### 2. Verify your installation

# 

# After installing the required tools, open a terminal and verify that each tool is available.

# 

# \#### Windows

# 

# Open \*\*Command Prompt\*\*, \*\*PowerShell\*\*, or the \*\*VS Code terminal\*\* and run:

# 

# ```bash

# python --version

# git --version

# conda --version

# ```

# 

# \#### macOS

# 

# Open \*\*Terminal\*\* and run:

# 

# ```bash

# python3 --version

# git --version

# conda --version

# ```

# 

# > \*\*Note:\*\* On Windows, Python is commonly accessed using `python`, while on macOS it is often accessed using `python3`.

# 

# \### Check your Conda installation

# 

# Run:

# 

# ```bash

# conda --version

# ```

# 

# To see the available Conda environments:

# 

# ```bash

# conda env list

# ```

# 

# If all commands return version information without errors, your basic development environment is ready.
